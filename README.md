# Penjelasan
SQL Injection adalah sebuah kerentanan yang di mana penyerang bisa melakukan injeksi ke enpoint yang rentan menggunakan query dari SQL itu sendiri.

---

# Apa saja yang bisa di lakukannya dan apa saja dampaknya?
Endpoint yang rentan terhadapa SQLi dan di susupi payload berbahaya oleh penyerang akan menyebabkan beberapa hal:
1. Penyerang dapat mengambil data pengguna lain;
2. Penyerang dapat login ke akun orang lain tanpa password; dan
3. Penyerang dapat melihat isi data sensitif pada database sistem;
